# QEQC Question Bank Quiz

Static, deployable quiz website built from the uploaded **Quantum Entanglement & Quantum Computing Units 1 & 2 Question Bank**. The bank contains 240 questions: 230 MCQs and 10 four-mark subjective questions.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other** (or leave auto-detected).
4. Build command: none. Output directory: `.`
5. Deploy.

You can also drag the folder into a compatible static-hosting workflow. No backend, database, API key, or environment variables are required.

## Features
- Unit 1 / Unit 2 filters
- 1 / 2 / 4 mark filters
- MCQ / subjective filters
- Full-text search
- Random 20 mode
- Instant answer feedback and worked solutions
- Progress + score persisted in localStorage
- Responsive mobile layout
- Dark/light toggle

Source: uploaded QEQC Units 1 & 2 question bank PDF.
